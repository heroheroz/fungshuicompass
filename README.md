# 風水羅盤

A single-page feng shui compass for floor plans: overlay a luopan, mark the door, windows, rooms and furniture, and read Na Qi (納氣), Flying Stars (玄空飛星) or Eight Mansions (八宅). Everything runs in the browser; uploaded plans never leave the device.

Live site: https://heroheroz.github.io/fungshuicompass/
